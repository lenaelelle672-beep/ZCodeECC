# ZCodeECC workspace projection

Generated from ECC 2.2.0: 67 agents, 284 skills, 94 commands, 122 rules, 21 hooks, and 36 optional MCP definitions.

Do not edit generated files directly. Change the canonical ECC source or `scripts/zcode/`, then run `npm run build:zcode`.

This workspace projection does not activate hooks by itself. Use the isolated plugin under `plugins/zcode-ecc/` for native plugin loading.

MCP servers are not enabled by the plugin. Review the disabled fragments under `.zcode/mcp/servers/` and opt in one server at a time.
